This is the LaTeX resume template I use. It's based on [Sourabh Bajaj's resume](https://github.com/sb2nov/resume), which is where the original design comes from.

## What's in the repo

- `cv-template.tex`: the blank template, with placeholders and comments explaining each section
- `cv-exemplo.tex`: the same template filled in with a made-up person, so you can see how it looks
- compiled PDFs of both

The easiest way to use it is to upload `cv-template.tex` to Overleaf and compile it there. You can also run `pdflatex cv-template.tex` locally. Then replace everything in `[brackets]` with your own information and delete the sections you don't need.

The template and the example were written with the help of LLMs, and the example data is fictional.
